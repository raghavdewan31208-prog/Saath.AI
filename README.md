# Saath.AI PPS Lab

A browser-based C++17 exam practice workspace for first-year PPS practical preparation.

The live site is deployed with GitHub Pages. C++ compilation and execution use the bundled local Clang/WASI WebAssembly toolchain. No public Judge0 endpoint or API key is required.

## Use
Open the GitHub Pages URL in a modern browser. No local installation is required.

## Features
- 144 full-code questions (80 existing + 64 syllabus-focused exam questions)
- 25 debugging exercises
- 20 fill-in-code exercises
- 12 output-prediction questions
- Ten dedicated units: Conditions & Loops, 1D Arrays, 2D Arrays and Matrices, Searching, Sorting, Pointers and Pointer Arithmetic, Pointer to Pointer and Arrays of Pointers, Dynamic Memory Allocation, Functions, and Recursion
- Four evaluation cases per new exam question, with samples, hints and hidden-in-app solutions
- Configurable mock exams: select units, set question count, and choose any 1–240 minute duration (30, 60 and 70 minute presets included)
- Timed exam navigation, mark-for-review palette, automatic submission, and topic-wise results
- Browser-local progress tracking
- C++17 compilation via the bundled local Clang/WASI compiler

Note: This is a static personal practice site. Question data and evaluation logic are shipped to the browser and are not suitable for secure or high-stakes assessment.
